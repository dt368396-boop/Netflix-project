# 🎬 Netflix Data Analysis Project

Data Analysis of Netflix Movies & TV Shows using Python, Pandas, Matplotlib and Seaborn.

## Features
- Total Movies vs TV Shows Analysis
- Most Popular Genres & Countries
- Content Added Over Years
- Top Directors & Actors
- Ratings Distribution
- Beautiful Visualizations

## Tech Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
Netflix Titles Dataset from Kaggle

## How to Run
pip install -r requirements.txt
python main.py
